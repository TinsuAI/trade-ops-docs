Quy ước nhóm file

Cách hệ thống tổ chức file — không tạo folder cứng.

Hồ sơ là đơn vị chính
File group theo hồ sơ liên kết. Trong mỗi hồ sơ, file group theo loại (hợp đồng, hoá đơn, vận đơn, BOM lưu chụp, đơn đề nghị cấp C/O, ...).
Hồ sơ chính vs tham chiếu
1 file có 1 hồ sơ chính + N hồ sơ tham chiếu (ví dụ TKNK feeds nhiều C/O xuất). Lock semantics theo hồ sơ chính. Không phải copy file — link logic.
Master + Hồ sơ động
2 master cố định: Hồ sơ thương nhân (đăng ký BCT) và Dữ liệu nền (BOM/item master/Mẫu 27). Hồ sơ động (CO/BCQT/KTSTQ) snapshot từ master tại thời điểm cấp.
Trạng thái = trạng thái hồ sơ
File không có trạng thái riêng. "Đã chốt" nghĩa là hồ sơ chứa file đó đã chốt — không sửa được nữa.
Retention layered
Mỗi file có "giữ đến MM/YYYY" tính theo rule áp dụng: 5y từ C/O cấp (Điều 30 NĐ 31/2018), 5y từ TKHQ đăng ký (Điều 18 LHQ), 10y từ ngày kế toán (Luật KT). Hệ thống tự tính.
Provenance eCoSys
File auto-pull từ eCoSys giữ API_REF + signature cơ quan — không sửa được sau khi pull. Đây là chuỗi tin cậy nhất phục vụ KTSTQ.
