Quy ước nhóm file

Cách hệ thống tổ chức file — không tạo folder cứng.

Hồ sơ là đơn vị chính
File group theo hồ sơ liên kết. Trong mỗi hồ sơ, file group theo loại (hợp đồng, hoá đơn, vận đơn, BOM lưu chụp, đơn đề nghị cấp C/O, ...).
Many-to-many
1 file có thể xuất hiện trong nhiều hồ sơ (ví dụ TKNK feeds nhiều C/O xuất). Không phải copy file — link logic. Phân biệt "hồ sơ chính" và "hồ sơ tham chiếu".
Master + Hồ sơ động
2 nhóm hồ sơ master cố định: Hồ sơ thương nhân (đăng ký BCT) và Dữ liệu nền (BOM/item master/định mức). Các hồ sơ động (CO, BCQT, KTSTQ) snapshot từ master tại thời điểm cấp.
Trạng thái = trạng thái hồ sơ
File không có trạng thái riêng. "Đã chốt" nghĩa là hồ sơ chứa file đó đã chốt — không sửa được nữa.
Backlog là hồ sơ riêng
File chưa ghép vào hồ sơ nào → group "Chưa ghép". Đây là 42 file mới vào tuần này — action chính của staff đại lý.
Cross-cut view
Có thể xem nhanh "tất cả hoá đơn" / "tất cả file 2024" / "tất cả file từ Zalo" qua tab Theo loại / Theo năm / Theo nguồn — cùng dữ liệu, góc nhìn khác.
